Diretivas Internas: Agent Skills de Design e Marketing

Documento de referencia para uso das skills instaladas neste repositorio. O objetivo e orientar Copilot, Codex e agentes humanos sobre quando usar cada skill sem alterar a aplicacao.

Diretorio principal: .github/skills Arquivo de gatilhos: .github/copilot-instructions.md Status: validado localmente

Regra Principal

Use estas skills para orientar criacao, implementacao e auditoria de interfaces e campanhas de e-mail. Nenhuma campanha deve ser enviada, agendada ou publicada automaticamente. Qualquer envio real exige confirmacao humana explicita.

Fluxos Recomendados

Interface nova ou redesign

  1. Use /ui-ux-pro-max para propor uma direcao visual resumida antes de programar.
  2. Use /frontend-ui-engineering para implementar o layout aprovado.
  3. Use /web-design-guidelines para revisar responsividade, acessibilidade e UX apos a implementacao.

Campanha de e-mail

  1. Use /email-marketing-bible para estrategia, publico, sequencia, entregabilidade e compliance.
  2. Use /email-design para definir conceito visual, composicao e briefing.
  3. Use /email-html-mjml para gerar MJML e HTML responsivo.

Principios do Projeto

  • Evitar interfaces genericas com aparencia evidente de conteudo gerado por IA.
  • Antes de programar uma interface nova, apresentar uma direcao visual resumida.
  • Reutilizar o design system, componentes e padroes ja existentes no projeto.
  • Priorizar responsividade real para desktop e mobile.
  • Nao alterar a identidade visual global sem autorizacao.
  • Em e-mails, nao gerar HTML moderno comum como se fosse uma pagina web.
  • Para e-mails, considerar limitacoes de Gmail, Outlook e Apple Mail.
  • Usar texto editavel para informacoes importantes, evitando transformar tudo em imagem.
  • Nunca enviar, agendar ou publicar uma campanha automaticamente.
  • Qualquer envio real exige confirmacao humana explicita.

Validacao Executada

  • Todos os SKILL.md possuem frontmatter com name e description.
  • Os nomes das skills sao unicos.
  • As referencias locais mencionadas nos SKILL.md existem.
  • Links Markdown relativos foram verificados sem quebras.
  • gh skill publish .github\skills --dry-run passou.

Riscos e Limitacoes

  • O repositorio da Vercel para web-design-guidelines nao trouxe arquivo LICENSE; por isso foi criado um adaptador local, sem copiar o conteudo upstream sem licenca.
  • email-html-mjml declara MIT no SKILL.md e no README upstream, mas nao trouxe arquivo LICENSE separado.
  • O dry-run do GitHub CLI avisou que nao ha ruleset de protecao de tags; isso afeta publicacao/release, nao a instalacao local.
  • Para o Copilot reconhecer as skills, recarregue a janela do VS Code ou inicie uma nova conversa.
